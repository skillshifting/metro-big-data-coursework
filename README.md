# Курсовая: Анализ пассажиропотока Московского метрополитена

## Тема

Анализ пассажиропотока Московского метрополитена с использованием технологий Big Data.

## Цель

Создать хранилище данных для анализа пассажиропотока Московского метрополитена, обработать исходные данные, построить аналитические витрины и визуализировать результаты.

## Данные

Данные взяты с портала открытых данных правительства Москвы

## Архитектура

CSV → staging → core → mart → Apache Superset

- `staging` — очищенные данные из исходных CSV
- `core` — нормализованные сущности и связи
- `mart` — готовые аналитические витрины
- `Superset` — графики и дашборды
